  1. What is the minimum, maximum, and mean length (in days) of observation from the synthetic dataset? (Hint: you can use the DATEDIFF function to compute the time between two dates.)

Source: https://ohdsi.r-universe.dev/DatabaseConnector/doc/manual.html

library(DatabaseConnector)

cd_synthetic <- createConnectionDetails(
  dbms   = "duckdb",
  server = "data/synthetic.duckdb"
)
conn_synthetic <- connect(cd_synthetic)
# compute the length of each observation period (each row)
# DATEDIFF produces one number per row & 'day' argument is the units

sql <- "
  SELECT MIN(DATEDIFF(day, observation_period_start_date, observation_period_end_date)) AS min_days,
         MAX(DATEDIFF(day, observation_period_start_date, observation_period_end_date)) AS max_days,
         AVG(DATEDIFF(day, observation_period_start_date, observation_period_end_date)) AS mean_days
  FROM @cdm.observation_period;"

renderTranslateQuerySql(conn_synthetic, sql, cdm = "main")
  min_days max_days mean_days
1        0    40509  13683.69

  1. How many people have at least one prescription of celecoxib from the Eunomia dataset? (Note: there’s an easy way to do this, using DRUG_ERA, and a harder way using DRUG_EXPOSURE and CONCEPT_ANCESTOR. Can you do both?)
  • DRUG_ERA, DRUG_EXPOSURE & CONCEPT_ANCESTOR are all tables under the main Schema
  • DRUG_ERA can be directly filtered by the ingredient_ID level
  • DRUG_EXPOSURE records specific products (e.g. Ibuprofen 200 MG Oral tablets)
  • CONCEPT_ANCESTOR links the ingredient (ancestor) to products containing it
# identify the celecoxib concept_id & identify its concept_class_id as ingredient

DatabaseConnector::querySql(conn, "
  SELECT concept_id, concept_name, concept_class_id
  FROM main.concept
  WHERE LOWER(concept_name) = 'celecoxib'
    AND vocabulary_id = 'RxNorm'")
